# Vestibulando

Roteiro de de todos os conteudos do ensino médio para para provas e vestibulares.

## Baixar PDFs

[ultimo release](https://github.com/Darya-Org/vestibulando/releases/latest)

## Contribuir

- Use sempre a ultima versão do compilador de typst;
- Fotos ou documentos **autorais** para os PDFs são super bem vindos mas lembre-se de deixa-los em `src/.figures`;
- Conteudo de IA é permitido apenas em códigos para **estilização do documento**, contanto que seja explicitamente demarcado como tal.
